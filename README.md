# 函數圖形試煉塔 v1.0.1

高中一次、二次、三次多項式圖形複習，支援三位學生在同一面觸控螢幕上各自闖關、各自換人。

## 立即遊玩

解壓縮後直接以 Edge 或 Chrome 開啟 `index.html`。沒有套件安裝、建置、外部字型、CDN 或伺服器依賴，離線也可遊玩。請保留 `index.html`、`styles.css`、`core.js`、`app.js`、`icon.svg` 在同一資料夾。

建議教室螢幕採 16:9 橫向，瀏覽器顯示範圍至少 1280 × 720。右上角可直接按「全螢幕」；「教師工具」仍需長按 1.5 秒進入。窄螢幕會將三區上下排列。

## v1.0.1 更新

- 右上角新增獨立全螢幕按鈕，進入後可按同一按鈕離開。
- 各類題目都顯示函數式，一次為 f(x) = mx + b，二次為 f(x) = ax² + bx + c；三次依題型顯示一般式或平移式。
- 三圖配對改用精簡的題頭與操作列，將更多高度留給圖形，放大曲線標籤與坐標標示。
- 個人進度以醒目的「2/8」表示目前第 2 關、全局共 8 關。

## 上傳 GitHub Pages

1. 在 GitHub 建立儲存庫，或開啟已有的儲存庫。
2. 將本壓縮檔**解壓縮後的內容**上傳到儲存庫根目錄。`index.html` 應直接出現在根目錄，請勿只上傳 ZIP，也不要多包一層資料夾。
3. 到儲存庫 Settings → Pages，選擇 Deploy from a branch。
4. Branch 選 main，資料夾選 `/ (root)`，按 Save。
5. 發佈完成後，開啟 Pages 提供的網址。所有檔案皆使用相對路徑，可放在任何儲存庫名稱下。

## 題目與教師設定

- 預設啟用一次、二次；可複選一次／二次／三次，至少保留一類。
- 每類固定四題：方向、係數綜合、陡緩或寬窄、三條函數圖形配對。
- 每類每題時間可分別調整，預設都是 30 秒，範圍 10～120 秒，每次調整 5 秒。
- 預設八題，最多作答四分鐘，加上正解與轉場約四分三十秒；答得快或被扣秒會提前完成。
- 三圖配對也是一題，使用該類同樣的秒數。
- 三區的題型順序一致，數字、方向及答案位置各自隨機。
- 設定只套用下一位開始的遊戲，已在進行的遊戲保留原設定。
- 深色「午夜藍金」與淺色「象牙白金」可切換；音效預設關閉。

## 計分與三秒冷卻

- 送出答對：得分 = 畫面顯示的剩餘整秒 + 10。倒數顯示使用剩餘實際時間向上取整，因此最後不足一秒仍顯示 1 秒，答對得 11 分。
- 送出答錯：本題剩餘實際時間扣 10 秒，出現提示，**鎖定送出 3 秒**。
- 冷卻期間倒數繼續，可以更換選擇，但不能再次送出，也不會重複扣秒。
- 冷卻解除後再次答錯，會再次扣 10 秒並重新冷卻。
- 扣秒後為 0 或負值，或自然時間到：立即展示正解，本題 0 分。
- 送出時若已到截止時間，先依超時處理，不會補給分。
- 配對題三組全部正確才給分；每次送出只判分一次、扣秒一次。答錯後保留正確配對，供學生修正其他配對。
- 答對展示約 1.2 秒、超時展示約 3.2 秒後自動下一題，展示時間不占下一題的作答秒數。

## 數學出題原則

- 一次：斜率方向、截距正負（含零）、同截距下的斜率絕對值、三線配對。
- 二次：最高次項係數的正負、`ab` 判斷頂點左右、`c` 判斷 y 軸截距、同頂點同方向的寬窄比較、三圖配對。
- 三次：兩端走向、平移式中 `a` 與 `p` 的符號、中心位置、純三次曲線的寬窄與三圖配對。
- 三次的兩端方向不等同於全程遞增／遞減。
- 寬窄比較一律固定坐標比例；二次固定頂點；三次固定對稱中心且令 `p = 0`，不將含一次項的所有三次曲線誤作等比例寬窄變化。
- 函數圖形由實際函數值繪成 SVG，係數與答案使用同一題目資料，分數以水平分數線呈現。

## 觸控與防誤觸

- Pointer Events 按下立即選取，接受第二、第三個非主要觸點，依 pointerId 分開處理。
- 選取圖卡與送出分開，配對使用每列大型 A／B／C 按鈕，無須點細線或拖曳。
- 同一觸碰的後續 click 去重；僅鎖定該玩家該題，沒有全螢幕共用冷卻。
- 觸點取消、失去捕獲、視窗失焦時清理觸點狀態。
- 遊戲操作區停用長按選字、右鍵功能選單與手勢捲動；教師工具須長按 1.5 秒，移動手指可取消。
- 教師工具中的「觸控測試」顯示三區接收次數與最大同時觸點數。
- 瀏覽器未收到的觸控訊號無法由網頁補回。可用觸控測試比較 HDMI + USB Touch、USB-C、AirSync 等連線的實際接收狀況。

## 成績

結算畫面最上方可填下一位姓名並直接開始，不影響另外兩區。此瀏覽器保留最近 120 筆成績，教師工具可匯出 UTF-8 CSV，用 Excel 開啟。比較分數請使用相同題目與秒數設定；不同裝置／瀏覽器的成績不會自動同步。瀏覽器若封鎖本機儲存，遊戲仍可運作，但成績只保留到本次頁面關閉。
